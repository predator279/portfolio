FINTECH

Supreme IPO

AI-Powered Financial Intelligence Platform · ipo.supreme.codes

End-to-end agentic RAG platform for Indian IPO analysis. Financial prospectuses (Red Herring Prospectuses - RHP) are frequently 500+ pages of dense regulatory filings. Supreme IPO automates data ingestion directly from SEBI and NSE, extracting 45+ structured parameters across 7 analytical categories.

Key Engineering Highlights:

  • Dual-Pass Parsing Pipeline: Built with PyMuPDF and pdfplumber with Table-of-Contents guided chunking that skips ~80% of boilerplate legal text.
  • Hybrid Vector Retrieval: Combines dense semantic search (MiniLM, MMR k=10) with sparse BM25 retrieval via LangChain's EnsembleRetriever, merging into context via Gemini 3.1 Flash Lite.
  • Production Deployment: Deployed on Azure Function Apps with CI/CD GitHub Actions, automated WAF-bypass cookie injection for NSE endpoints, and nightly pre-caching.
Agentic RAG BM25 & MiniLM Qdrant Azure Functions FastAPI

HR-TECH

ResumeX

AI Resume Screener & ATS Intelligence Engine · resumex.supreme.codes

AI-powered resume screening platform that predicts job roles and ranks candidates against comprehensive job descriptions using a fine-tuned BERT classifier and a custom 5-dimension ATS scoring engine.

Key Engineering Highlights:

  • Fine-tuned BERT Classifier: Multi-label classifier trained on ~14,000 resumes across 43 job categories, achieving 98% Top-5 accuracy for role classification.
  • 5-Dimension ATS Scoring: Engineered ranking across skills, experience, semantic similarity, education, and seniority with hard caps for mismatches.
  • Resource-Constrained EC2 Deployment: Deployed async FastAPI backend on AWS EC2 t2.micro via Docker, optimized for 1GB RAM constraint using swap space and CPU-only PyTorch wheels.
  • MLOps Observability: Full Prometheus and Grafana monitoring exposing custom ML metrics for BERT inference latency, throughput, and classifier confidence.
